# Mimk
«Автоматизированная система учёта групп, нагрузки и оплаты преподавателей на курсах повышения квалификации МиМК».
# АИС «Курсы повышения квалификации» (МиМК)

Данный репозиторий содержит исходный код и документацию автоматизированной информационной системы для учёта курсов повышения квалификации в ГБПОУ «Миасский машиностроительный колледж».

## Функциональные возможности
- Ведение групп (специальность, отделение, количество слушателей)
- Учёт преподавателей (ФИО, телефон, стаж)
- Распределение нагрузки (часы, тип занятий, предмет)
- Автоматический расчёт оплаты труда (лекции/практика)
- Формирование отчётов

## Технологии
- СУБД: PostgreSQL
- Бэкенд: Python/Django
- Фронтенд: HTML/CSS/JS

## Установка и запуск
1. Клонировать репозиторий: `git clone https://github.com/username/kursy-pk-mimk.git`
2. Установить зависимости: `pip install -r requirements.txt`
3. Выполнить миграции: `python manage.py migrate`
4. Запустить сервер: `python manage.py runserver`
